🤖 AI के साथ अपना खुद का वीडियो गेम बनाइए

अपने कंप्यूटर पर करने के लिए चरण-दर-चरण गाइड। आपको कोडिंग आना ज़रूरी नहीं है!

← गेम्स पर वापस जाएँ

💡 आपको इंटरनेट वाला कंप्यूटर चाहिए और, अगर आप 18 साल से कम उम्र के हैं, तो अकाउंट बनाने के लिए किसी बड़े की मदद चाहिए।

1Visual Studio Code इंस्टॉल करें

Visual Studio Code (हम इसे VS Code कहते हैं) वह प्रोग्राम है जिसमें आप AI के साथ काम करेंगे। यह मुफ़्त है।

  1. code.visualstudio.com/download पर जाइए।
  2. अपने कंप्यूटर (Windows, Mac या Linux) वाले बटन पर क्लिक कीजिए।
  3. डाउनलोड हुई फ़ाइल खोलिए और खत्म होने तक "Next" पर क्लिक करते रहिए।
  4. VS Code खोलिए। हो गया!

2Copilot चालू करें, आपका AI सहायक

GitHub Copilot वह कृत्रिम बुद्धिमत्ता है जो आपका गेम बनाएगी। आज़माने के लिए इसका एक मुफ़्त वर्ज़न है।

  1. github.com पर मुफ़्त अकाउंट बनाइए (किसी बड़े की मदद से)।
  2. VS Code में नीचे दाईं ओर देखिए: आपको Copilot का आइकन दिखेगा। उस पर क्लिक कीजिए।
  3. "Sign in" (साइन इन) पर क्लिक कीजिए और अपने GitHub अकाउंट से लॉग इन कीजिए। ब्राउज़र खुलेगा: "Authorize" पर क्लिक कीजिए।
  4. अगर कोई प्लान दिखाया जाए तो Copilot Free (मुफ़्त) चुनिए।
  5. Copilot की चैट खुल जाती है। जहाँ आप टाइप करते हैं उसके नीचे एक मॉडल (AI का "दिमाग") के नाम वाला बटन होता है। उस पर क्लिक कीजिए और बिना ताले वाला कोई एक मॉडल चुनिए। मुफ़्त प्लान में हर महीने सीमित संदेश मिलते हैं, इसलिए उन्हें सोच-समझकर इस्तेमाल कीजिए!

💡 अगर आपको चैट नहीं दिख रही, तो एक साथ Ctrl + Alt + I दबाइए (Mac पर: Control + Cmd + I)।

3वर्कशॉप डाउनलोड करें

AI को आपका मार्गदर्शन करने के लिए जो कुछ चाहिए, वह सब यहाँ है।

  1. github.com/deroki/basf_games_ai_workshop पर जाइए।
  2. हरे "Code" बटन पर क्लिक कीजिए और फिर "Download ZIP" पर।
  3. फ़ाइल को Downloads फ़ोल्डर में ढूँढिए, उस पर राइट-क्लिक कीजिए और "Extract All" चुनिए (Mac पर डबल-क्लिक कीजिए)।
  4. VS Code में File → Open Folder पर क्लिक कीजिए और अभी निकाला हुआ फ़ोल्डर चुनिए।
  5. अगर पूछा जाए "क्या आप लेखकों पर भरोसा करते हैं?", तो "Yes, I trust the authors" पर क्लिक कीजिए।

4अपना गेम बनाइए

  1. Copilot की चैट में /create_game लिखिए और Enter दबाइए। इस तरह आप गेम बनाने वाले AI को जगा देते हैं!
  2. उसके सवालों के जवाब दीजिए। पहले वह पूछता है कि टीम में आप कितने लोग हैं, फिर गेम कैसा है, किरदार कौन है, एडवेंचर कहाँ होता है और दुश्मन कौन हैं। कुछ सवालों का जवाब पूरी टीम देती है और कुछ का हर खिलाड़ी बारी-बारी से। आप उसे कोई ड्रॉइंग भी दिखा सकते हैं!
  3. "OK" कहिए। AI आपको बताता है कि आपका गेम कैसा होगा। अगर आपको पसंद आए, तो उसे बता दीजिए।
  4. जादू! AI गेम बना देता है और वह खेलने के लिए आपके ब्राउज़र में खुल जाता है। इसे कीबोर्ड से चलाया जाता है।
  5. सुधार माँगिए: और तेज़, ज़्यादा दुश्मन, बेहतर चित्र… जितनी बार चाहें, जब तक आप न कह दें "बस, मुझे बहुत पसंद आया!"।

💡 तरकीब: आप अपने आइडिया जितने अच्छे से समझाएँगे, आपका गेम उतना ही अच्छा बनेगा। अगर कुछ काम न करे, तो AI को अपने शब्दों में बता दीजिए!

5जब चाहें दोबारा खेलिए

आपका गेम वर्कशॉप फ़ोल्डर के अंदर games फ़ोल्डर में सेव होता है। दोबारा खेलने के लिए अपने गेम का फ़ोल्डर खोलिए और index.html फ़ाइल पर डबल-क्लिक कीजिए। इंटरनेट की ज़रूरत नहीं है।
