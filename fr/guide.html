🤖 Crée ton propre jeu vidéo avec l'IA

Un guide pas à pas pour le faire sur ton ordinateur. Pas besoin de savoir programmer !

← Retour aux jeux

💡 Il te faut un ordinateur avec internet et, si tu es mineur, l'aide d'un adulte pour créer tes comptes.

1Installe Visual Studio Code

Visual Studio Code (on l'appelle VS Code) est le programme où tu vas travailler avec l'IA. Il est gratuit.

  1. Va sur code.visualstudio.com/download.
  2. Clique sur le bouton correspondant à ton ordinateur (Windows, Mac ou Linux).
  3. Ouvre le fichier téléchargé et clique sur « Suivant » jusqu'à la fin.
  4. Ouvre VS Code. C'est prêt !

2Active Copilot, ton assistant IA

GitHub Copilot est l'intelligence artificielle qui va créer ton jeu. Il existe une version gratuite pour essayer.

  1. Crée un compte gratuit sur github.com (avec l'aide d'un adulte).
  2. Dans VS Code, regarde en bas à droite : tu verras l'icône de Copilot. Clique dessus.
  3. Clique sur « Sign in » (se connecter) et connecte-toi avec ton compte GitHub. Ton navigateur s'ouvre : clique sur « Authorize ».
  4. Si on te propose un plan, choisis Copilot Free (gratuit).
  5. Le chat de Copilot s'ouvre. Sous la zone où tu écris, il y a un bouton avec le nom d'un modèle (le « cerveau » de l'IA). Clique dessus et choisis-en un sans cadenas. Le plan gratuit te donne un nombre limité de messages par mois : utilise-les bien !

💡 Si tu ne vois pas le chat, appuie en même temps sur Ctrl + Alt + I (sur Mac : Control + Cmd + I).

3Télécharge l'atelier

Tout ce dont l'IA a besoin pour te guider est ici.

  1. Va sur github.com/deroki/basf_games_ai_workshop.
  2. Clique sur le bouton vert « Code » puis sur « Download ZIP ».
  3. Trouve le fichier dans ton dossier Téléchargements, fais un clic droit et choisis « Extraire tout » (sur Mac, double-clique).
  4. Dans VS Code, clique sur Fichier → Ouvrir le dossier et choisis le dossier que tu viens d'extraire.
  5. Si on te demande « Faites-vous confiance aux auteurs ? », clique sur « Oui, je fais confiance ».

4Crée ton jeu

  1. Dans le chat de Copilot, écris /create_game et appuie sur Entrée. Tu réveilles ainsi l'IA créatrice de jeux !
  2. Réponds à ses questions. Elle te demande d'abord combien vous êtes dans l'équipe, puis comment est le jeu, qui est le personnage, où se passe l'aventure et qui sont les ennemis. Certaines questions sont pour toute l'équipe et d'autres pour chaque joueur à tour de rôle. Tu peux même lui montrer un dessin !
  3. Dis « OK ». L'IA te raconte comment sera ton jeu. Si ça vous plaît, dis-le-lui.
  4. Magique ! L'IA crée le jeu et il s'ouvre dans ton navigateur pour jouer. Il se contrôle avec le clavier.
  5. Demande des améliorations : plus rapide, plus d'ennemis, de plus beaux dessins… autant de fois que vous voulez, jusqu'à dire « Ça y est, j'adore ! ».

💡 L'astuce : plus tu expliques bien tes idées, meilleur sera ton jeu. Si quelque chose ne marche pas, dis-le à l'IA avec tes propres mots !

5Rejoue quand tu veux

Ton jeu est enregistré dans le dossier games, à l'intérieur du dossier de l'atelier. Pour rejouer, ouvre le dossier de ton jeu et double-clique sur le fichier index.html. Pas besoin d'internet.
