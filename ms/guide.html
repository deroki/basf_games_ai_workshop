🤖 Cipta permainan video anda sendiri dengan AI

Panduan langkah demi langkah untuk dilakukan di komputer anda. Anda tidak perlu tahu cara membuat kod!

← Kembali ke permainan

💡 Anda memerlukan komputer dengan internet dan, jika anda di bawah umur, bantuan orang dewasa untuk membuat akaun anda.

1Pasang Visual Studio Code

Visual Studio Code (kita panggil VS Code) ialah program tempat anda akan bekerja dengan AI. Ia percuma.

  1. Pergi ke code.visualstudio.com/download.
  2. Klik butang untuk komputer anda (Windows, Mac atau Linux).
  3. Buka fail yang dimuat turun dan klik "Next" sehingga selesai.
  4. Buka VS Code. Siap!

2Aktifkan Copilot, pembantu AI anda

GitHub Copilot ialah kecerdasan buatan yang akan mencipta permainan anda. Ia mempunyai versi percuma untuk dicuba.

  1. Buat akaun percuma di github.com (dengan bantuan orang dewasa).
  2. Dalam VS Code, lihat di bahagian bawah kanan: anda akan nampak ikon Copilot. Klik padanya.
  3. Klik "Sign in" (log masuk) dan log masuk dengan akaun GitHub anda. Pelayar akan dibuka: klik "Authorize".
  4. Jika ditawarkan pelan, pilih Copilot Free (percuma).
  5. Sembang Copilot dibuka. Di bawah kotak tempat anda menaip, ada butang dengan nama sebuah model ("otak" AI). Klik dan pilih salah satu yang tersedia tanpa mangga. Pelan percuma memberi anda bilangan mesej yang terhad setiap bulan, jadi gunakan dengan bijak!

💡 Jika anda tidak nampak sembang, tekan Ctrl + Alt + I serentak (pada Mac: Control + Cmd + I).

3Muat turun bengkel

Semua yang AI perlukan untuk membimbing anda ada di sini.

  1. Pergi ke github.com/deroki/basf_games_ai_workshop.
  2. Klik butang hijau "Code" kemudian "Download ZIP".
  3. Cari fail dalam folder Downloads, klik kanan dan pilih "Extract All" (pada Mac, klik dua kali).
  4. Dalam VS Code klik File → Open Folder dan pilih folder yang baru anda ekstrak.
  5. Jika ditanya "Adakah anda mempercayai pengarang?", klik "Yes, I trust the authors".

4Cipta permainan anda

  1. Dalam sembang Copilot, taip /create_game dan tekan Enter. Dengan itu anda mengejutkan AI pencipta permainan!
  2. Jawab soalannya. Mula-mula ia bertanya berapa ramai dalam pasukan, kemudian bagaimana permainannya, siapa wataknya, di mana pengembaraan berlaku dan siapa musuhnya. Sesetengah soalan dijawab oleh seluruh pasukan dan yang lain oleh setiap pemain secara bergilir. Anda juga boleh menunjukkan lukisan kepadanya!
  3. Katakan "OK". AI memberitahu anda bagaimana permainan anda nanti. Jika anda suka, beritahu ia.
  4. Ajaib! AI mencipta permainan dan ia dibuka di pelayar untuk dimainkan. Anda mengawalnya dengan papan kekunci.
  5. Minta penambahbaikan: lebih laju, lebih banyak musuh, lukisan lebih cantik… sebanyak mana anda mahu, sehingga anda berkata "Dah siap, saya suka!".

💡 Rahsianya: semakin baik anda menerangkan idea anda, semakin baik permainan anda. Jika sesuatu tidak berfungsi, beritahu AI dengan perkataan anda sendiri!

5Main semula bila-bila masa

Permainan anda disimpan dalam folder games, di dalam folder bengkel. Untuk bermain semula, buka folder permainan anda dan klik dua kali fail index.html. Anda tidak perlukan internet.
