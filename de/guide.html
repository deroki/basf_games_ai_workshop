🤖 Erstelle dein eigenes Videospiel mit KI

Eine Schritt-für-Schritt-Anleitung für deinen Computer. Du musst nicht programmieren können!

← Zurück zu den Spielen

💡 Du brauchst einen Computer mit Internet und, wenn du minderjährig bist, die Hilfe eines Erwachsenen, um deine Konten zu erstellen.

1Installiere Visual Studio Code

Visual Studio Code (wir sagen VS Code) ist das Programm, in dem du mit der KI arbeitest. Es ist kostenlos.

  1. Geh auf code.visualstudio.com/download.
  2. Klick auf den Button für deinen Computer (Windows, Mac oder Linux).
  3. Öffne die heruntergeladene Datei und klick auf „Weiter“, bis alles fertig ist.
  4. Öffne VS Code. Geschafft!

2Aktiviere Copilot, deinen KI-Helfer

GitHub Copilot ist die künstliche Intelligenz, die dein Spiel erstellt. Es gibt eine kostenlose Version zum Ausprobieren.

  1. Erstelle ein kostenloses Konto auf github.com (mit Hilfe eines Erwachsenen).
  2. Schau in VS Code nach unten rechts: Dort siehst du das Copilot-Symbol. Klick darauf.
  3. Klick auf „Sign in“ (Anmelden) und melde dich mit deinem GitHub-Konto an. Der Browser öffnet sich: Klick auf „Authorize“.
  4. Wenn dir ein Tarif angeboten wird, wähle Copilot Free (kostenlos).
  5. Der Copilot-Chat öffnet sich. Unter dem Eingabefeld ist ein Button mit dem Namen eines Modells (dem „Gehirn“ der KI). Klick darauf und wähle eines ohne Schloss. Im kostenlosen Tarif hast du pro Monat nur eine begrenzte Anzahl an Nachrichten, nutze sie also gut!

💡 Wenn du den Chat nicht siehst, drück gleichzeitig Strg + Alt + I (am Mac: Control + Cmd + I).

3Lade den Workshop herunter

Hier ist alles, was die KI braucht, um dich zu führen.

  1. Geh auf github.com/deroki/basf_games_ai_workshop.
  2. Klick auf den grünen Button „Code“ und dann auf „Download ZIP“.
  3. Such die Datei im Ordner „Downloads“, klick mit der rechten Maustaste darauf und wähle „Alle extrahieren“ (am Mac: Doppelklick).
  4. Klick in VS Code auf Datei → Ordner öffnen und wähle den gerade entpackten Ordner.
  5. Wenn gefragt wird „Vertraust du den Autoren?“, klick auf „Ja, ich vertraue den Autoren“.

4Erstelle dein Spiel

  1. Schreib im Copilot-Chat /create_game und drück Enter. So weckst du die KI auf, die Spiele erschafft!
  2. Beantworte ihre Fragen. Zuerst fragt sie, wie viele ihr im Team seid, dann wie das Spiel ist, wer die Figur ist, wo das Abenteuer spielt und wer die Gegner sind. Manche Fragen beantwortet das ganze Team, andere jeder Spieler der Reihe nach. Du kannst ihr sogar eine Zeichnung zeigen!
  3. Sag „OK“. Die KI erzählt dir, wie dein Spiel wird. Wenn es euch gefällt, sagt es ihr.
  4. Magie! Die KI erstellt das Spiel und es öffnet sich zum Spielen im Browser. Du steuerst es mit der Tastatur.
  5. Bitte um Verbesserungen: schneller, mehr Gegner, schönere Bilder … so oft ihr wollt, bis ihr sagt: „Das war’s, ich liebe es!“.

💡 Der Trick: Je besser du deine Ideen erklärst, desto besser wird dein Spiel. Wenn etwas nicht funktioniert, sag es der KI mit deinen eigenen Worten!

5Spiel wieder, wann du willst

Dein Spiel wird im Ordner games im Workshop-Ordner gespeichert. Um wieder zu spielen, öffne den Ordner deines Spiels und mach einen Doppelklick auf die Datei index.html. Du brauchst kein Internet.
